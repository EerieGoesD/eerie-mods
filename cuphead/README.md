# Cuphead Mods

Mods for [Cuphead](https://store.steampowered.com/app/268910/Cuphead/) (Steam), including The Delicious Last Course.

Each mod is a [BepInEx 5](https://github.com/BepInEx/BepInEx) plugin. Each mod folder has the source and a `build.ps1` that compiles it and copies it into the game's `BepInEx\plugins` folder.

## Mods

| Mod | Description |
| --- | --- |
| [NoFlashing](NoFlashing) | Removes flashing, flickering, strobing and screen shake. |
