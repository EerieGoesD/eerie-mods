# No Flashing (Epilepsy Friendly)

Removes the flashing, flickering, strobing and screen shake in Cuphead and The Delicious Last Course.

- Bosses and enemies no longer flash when hit or when they die.
- The player no longer blinks after taking damage. They stay see-through until they can be hit again.
- The Ready / WALLOP! text at the start of a level no longer strobes.
- No explosion bursts when a boss is knocked out.
- No background lightning, flickering lights, Saltbaker sky flash or healing charm flash. Blinking prompts stay steady.
- The old-film grain is removed, or can be kept still.
- No screen shake.

Flashes drawn into the game's animations (super attacks, some projectiles) are not removed.

## Settings

Press F1 in game to open the settings window. Every setting is a switch and takes effect straight away.

- Remove hit flashes
- Remove player flashes
- Remove scenery flashes
- Steady level intro
- Remove boss explosions
- Film grain: Off, Still or Flickering
- Remove screen shake

The same settings are in `Cuphead\BepInEx\config\eeriegoesd.cuphead.noflashing.cfg`.

## Install

1. Install [BepInEx 5](https://github.com/BepInEx/BepInEx/releases) (the `win_x64` zip) into the Cuphead folder.
2. Install [ConfigurationManager](https://github.com/BepInEx/BepInEx.ConfigurationManager/releases) (the `BepInEx5` zip) the same way. This is the F1 settings window.
3. Copy `NoFlashing.dll` into `Cuphead\BepInEx\plugins`.
4. Start the game.
