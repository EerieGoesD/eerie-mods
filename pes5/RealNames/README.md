# Real Names

Renames the fake clubs, players, stadiums and competitions in Pro Evolution Soccer 5 to their real names.

- Clubs: 69 clubs in England, France, Germany and other leagues, with their real short names. For example Man Red becomes Manchester United (MAU).
- Players: the fake names in the Netherlands, Classic Brazil and Turkey squads and a few classic players, for example Roquel becomes Robben. Another 207 national team players get the real name the game already stores for them, for example Kaliko becomes Kuyt.
- Stadiums: 27 stadiums, for example Trad Brick Stadium becomes Old Trafford.
- Competitions: league and cup names, for example WEFA Championships becomes UEFA Champions League and England League becomes English Premiership.

A name you edit yourself in Edit mode is left alone.

Not renamed: players and stadiums missing from the lists below (for example Blautraum Stadion), and some Master League menu texts that still say WEFA.

## Requirements

- [PCSX2](https://pcsx2.net)
- Pro Evolution Soccer 5, PAL release, serial SLES-53544, CRC BFDF7C5A. The patch does not load for other regions or versions.

## Install

1. Copy `SLES-53544_BFDF7C5A.pnach` into the `patches` folder inside PCSX2's data folder. On a Steam Deck this is `/home/deck/.config/PCSX2/patches/`.
2. Open the game's Properties in PCSX2, go to Patches and tick **Real Names**.
3. Start the game.

If the `patches` folder already has a `SLES-53544_BFDF7C5A.pnach` of yours, copy the `[Real Names]` section into it instead of replacing the file.
