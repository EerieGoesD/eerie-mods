# Hinterland Mods

Mods for [Hinterland](https://store.steampowered.com/app/17140/) (Steam).

Each mod is a `tools` folder of TorqueScript that the game loads on its own: its `main.cs` already loads `tools\main.cs`, so no game file is changed.

## Mods

| Mod | Description |
| --- | --- |
| [GuidedPlayOverhaul](GuidedPlayOverhaul) | Guided play built around all 9 achievements: what to fight, wear, loot, hire, build and research next, with auto-attack, auto potion and potion buttons. |
